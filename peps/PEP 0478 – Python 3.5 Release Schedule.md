# Abstract

This document describes the development and release schedule for Python
3.5. The schedule primarily concerns itself with PEP-sized items.

# Release Manager and Crew

- 3.5 Release Manager: Larry Hastings
- Windows installers: Steve Dower
- Mac installers: Ned Deily
- Documentation: Georg Brandl

# Release Schedule

Python 3.5 has now reached its end-of-life and has been retired. No more
releases will be made.

These are all the historical releases of Python 3.5, including their
release dates.

- 3.5.0 alpha 1: February 8, 2015
- 3.5.0 alpha 2: March 9, 2015
- 3.5.0 alpha 3: March 29, 2015
- 3.5.0 alpha 4: April 19, 2015
- 3.5.0 beta 1: May 24, 2015 (Beta 1 is also \"feature freeze\"\--no new
  features beyond this point.)
- 3.5.0 beta 2: May 31, 2015
- 3.5.0 beta 3: July 5, 2015
- 3.5.0 beta 4: July 26, 2015
- 3.5.0 release candidate 1: August 10, 2015

# Features for 3.5

- `441`{.interpreted-text role="pep"}, improved Python zip application
  support
- `448`{.interpreted-text role="pep"}, additional unpacking
  generalizations
- `461`{.interpreted-text role="pep"}, \"%-formatting\" for bytes and
  bytearray objects
- `465`{.interpreted-text role="pep"}, a new operator (\"@\") for matrix
  multiplication
- `471`{.interpreted-text role="pep"}, os.scandir(), a fast new
  directory traversal function
- `475`{.interpreted-text role="pep"}, adding support for automatic
  retries of interrupted system calls
- `479`{.interpreted-text role="pep"}, change StopIteration handling
  inside generators
- `484`{.interpreted-text role="pep"}, the typing module, a new standard
  for type annotations
- `485`{.interpreted-text role="pep"}, math.isclose(), a function for
  testing approximate equality
- `486`{.interpreted-text role="pep"}, making the Windows Python
  launcher aware of virtual environments
- `488`{.interpreted-text role="pep"}, eliminating .pyo files
- `489`{.interpreted-text role="pep"}, a new and improved mechanism for
  loading extension modules
- `492`{.interpreted-text role="pep"}, coroutines with async and await
  syntax
