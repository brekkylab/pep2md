3.4. The schedule primarily concerns itself with PEP-sized items.

# Release Schedule

Python 3.4 has now reached its end-of-life and has been retired. No more
releases will be made.

These are all the historical releases of Python 3.4, including their

# Features for 3.4

Implemented / Final PEPs:

- `428`{.interpreted-text role="pep"}, a \"pathlib\" module providing
  object-oriented filesystem paths
- `435`{.interpreted-text role="pep"}, a standardized \"enum\" module
- `436`{.interpreted-text role="pep"}, a build enhancement that will
  help generate introspection information for builtins
- `442`{.interpreted-text role="pep"}, improved semantics for object
  finalization
- `443`{.interpreted-text role="pep"}, adding single-dispatch generic
  functions to the standard library
- `445`{.interpreted-text role="pep"}, a new C API for implementing
  custom memory allocators
- `446`{.interpreted-text role="pep"}, changing file descriptors to not
  be inherited by default in subprocesses
- `450`{.interpreted-text role="pep"}, a new \"statistics\" module
- `451`{.interpreted-text role="pep"}, standardizing module metadata for
  Python\'s module import system
- `453`{.interpreted-text role="pep"}, a bundled installer for the *pip*
  package manager
- `454`{.interpreted-text role="pep"}, a new \"tracemalloc\" module for
  tracing Python memory allocations
- `456`{.interpreted-text role="pep"}, a new hash algorithm for Python
  strings and binary data
- `3154`{.interpreted-text role="pep"}, a new and improved protocol for
  pickled objects
- `3156`{.interpreted-text role="pep"}, a new \"asyncio\" module, a new
  framework for asynchronous I/O

Deferred to post-3.4:

- `431`{.interpreted-text role="pep"}, improved support for time zone
  databases
- `441`{.interpreted-text role="pep"}, improved Python zip application
  support
- `447`{.interpreted-text role="pep"}, support for \_\_locallookup\_\_
  metaclass method
- `448`{.interpreted-text role="pep"}, additional unpacking
  generalizations
- `455`{.interpreted-text role="pep"}, key transforming dictionary
